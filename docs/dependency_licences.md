# Dependencies and licences

## Runtime/build dependencies
- C++17 standard library: supplied by the compiler toolchain; implementation is compiler/runtime dependent.
- CMake 3.20 or newer: build-system dependency.
- Threads: C++ standard threading library / platform threading runtime.
- GNU C++ 14.2.0 was used for the included Linux build.
- Matplotlib and NumPy were used only in the development workspace to generate report plots; they are not runtime dependencies of the C++ executable.

No commercial solver, CAD application, paid AI service, or physical hardware is required by this prototype. Verify and record the exact licences/versions of any tools installed on the target Windows build host before redistribution.
